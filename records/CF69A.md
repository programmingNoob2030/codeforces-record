# CF 69A

## 基本信息

- 日期: 2026-08-23
- 分类: implementation / math
- 难度: 1000


## 题目简述

给定 n 个三维向量。
计算所有向量的和，如果最终得到的向量为 `(0,0,0)`，则说明系统平衡，输出 `YES`，否则输出 `NO`。


## 我的第一印象

刚开始看到题目中的物体受力和平衡，第一反应是需要一些物理知识。
但是进一步观察输入，发现每个力都由三个方向分量 `x、y、z` 表示。
因此问题本质不是物理分析，而是判断所有三维向量相加后是否为零向量。


## 最终解法

使用三个变量分别维护三个方向上的合力：
- x 方向累计所有 xi
- y 方向累计所有 yi
- z 方向累计所有 zi
遍历所有力，将对应分量累加。
最后判断：
- x == 0
- y == 0
- z == 0
如果三个方向都为 0，则说明合力为 0，输出 YES。
否则输出 NO。


## 复杂度

Time: O(n) Space: O(1)


## 不足

- 容易被题目的现实背景影响，没有第一时间抽象出数学模型。
- 需要加强从题目描述中提取变量关系的能力。
