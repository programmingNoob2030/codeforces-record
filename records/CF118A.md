# CF 118A

## 基本信息

- 日期: 2026-08-22
- 分类: implementation / strings
- 难度: 1000


## 题目简述

给定一个由大小写英文字母组成的字符串。
需要删除其中的元音字母：
`A、E、I、O、U、Y`
然后将剩余字母转换为小写，并在每个字母前添加 `.`。


## 我的第一印象

第一反应是直接遍历字符串，遇到元音就跳过，否则输出 `.` 和对应字符。
中途考虑过使用 `set + vector`，但发现没有必要，直接遍历即可完成。
一开始想通过 ASCII 码：
~~~cpp
char c = s + 32;
~~~
来将大写字母转换成小写，但这种方法无法同时正确处理本身已经是小写的字母。
询问 AI 后了解到 `cctype` 库可以用于字符处理，其中 `tolower()` 可以直接完成大小写转换。


## 最终解法

直接遍历字符串：
1. 判断当前字符是否为元音。
2. 如果是元音，跳过。
3. 如果不是元音，输出 `.`。
4. 使用 `tolower()` 将字符转换为小写后输出。
核心代码：
~~~cpp
if (is_vowel(s)) continue;
cout << '.' << char(tolower(s));
~~~
不需要使用额外的 `set` 或 `vector`。


## 复杂度

Time: O(n)

 Space: O(1)


## 不足

- 一开始考虑了 `set + vector` 等不必要的数据结构，没有第一时间意识到单次遍历即可解决。
- 对 ASCII 大小写转换规则理解不够准确，尝试使用 `+32` 进行转换。
- 对 C++ 标准库中的字符处理函数还不够熟悉，需要继续熟悉 `cctype` 中常用函数的使用。
