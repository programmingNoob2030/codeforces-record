# CF 479A

## 基本信息

- 日期: 2026-08-26
- 分类: brute force / math
- 难度: 1000


## 题目简述

给定三个整数 a、b、c。
在三个数字之间添加两个运算符（`+` 或 `*`），并可以加入括号，使表达式结果最大。
输出最大结果。


## 我的第一印象

看到“最大化结果”，第一反应想到 DP。
但是分析数据规模后发现：
- 只有三个数字
- 只有两个运算符位置
- 每个位置只有两种选择
- 括号情况有限
因此不需要设计 DP 状态。
直接枚举所有可能表达式即可。


## 最终解法

枚举所有可能的表达式：
不加括号：
- a + b + c
- a + b * c
- a * b + c
- a * b * c
带括号：
- (a + b) * c
- a * (b + c)
计算每种情况的结果，维护最大值。


## 复杂度

Time: O(1)

 Space: O(1)


## 不足

一开始容易被“最大值”误导，想到 DP。
对于小规模问题，需要优先分析：
- 数据范围
- 状态数量
- 是否可以直接枚举
避免过度设计。
