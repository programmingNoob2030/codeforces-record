# CF 339B

## 基本信息

- 日期: 2026-09-01
- 分类: implementation
- 难度: 1000


## 题目简述

有 `n` 个房屋组成一个环，按照顺时针方向编号。
从房屋 `1` 出发，需要按照任务编号的顺序依次完成 `m` 个任务。
每个任务要求到达指定的房屋，求完成所有任务所需要的最少移动时间。


## 我的第一印象

一开始对题目中的任务顺序描述理解得不太清楚，担心连续任务之间还存在额外的顺序限制。
重新分析后发现：
- 任务必须按照编号顺序完成；
- 移动方向固定为顺时针；
- 起点固定为房屋 `1`；
- 因此整个移动路线实际上是确定的，不存在路线选择。
只需要依次计算当前位置到下一个任务位置的顺时针距离即可。


## 最终解法

### 移动距离
对于当前位置 `current_pos` 和下一个任务位置 `next_pos`：
- `next_pos > current_pos`：直接移动 `next_pos - current_pos`
- `next_pos < current_pos`：需要绕过房屋 `n`，移动 `n - current_pos + next_pos`
- `next_pos == current_pos`：不需要移动
### 模拟过程
从房屋 `1` 开始：
1. 读取下一个任务的位置；
2. 计算当前位置到任务位置的顺时针距离；
3. 累加移动时间；
4. 更新当前位置；
5. 重复直到所有任务完成。


## 复杂度

Time: O(m)
 Space: O(1)
