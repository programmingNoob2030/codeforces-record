# CF 1374C

## 基本信息

- 日期: 2026-09-08
- 分类: greedy / strings
- 难度: 1000


## 题目简述

给定一个长度为 `n` 的括号字符串，每次可以将一个括号从 `(` 修改为 `)` 或从 `)` 修改为 `(`。
求最少需要修改多少个括号，才能使整个字符串成为合法括号序列。


## 我的第一印象

这题比预想中简单，本来还以为会有什么特殊套路。
仔细分析后发现，左右括号数量相同，因此真正需要关注的是右括号 `)`。
遇到左括号 `(` 时，可以先记录一个可用于匹配的左括号。
遇到右括号 `)` 时：
- 如果前面存在可以匹配的左括号，就直接匹配；
- 如果没有可用的左括号，说明当前右括号无法匹配，只能进行一次修改。
因此只需要维护当前剩余的左括号数量，以及需要修改的次数。


## 最终解法

从左到右遍历字符串
- 遇到 `(`：`lf++`
- 遇到 `)`：
  - 如果 `lf > 0`，使用一个左括号进行匹配，即 `lf--`；
  - 如果 `lf == 0`，当前右括号无法匹配，答案增加 `1`。
由于题目保证左右括号数量相同，因此统计过程中无法匹配的右括号数量，就是最终需要修改的最少次数。


## 复杂度

- Time: O(n)
- Space: O(1)


## 不足

- 对括号序列问题的核心性质已经能够较快识别，但还需要进一步形成更稳定的“维护当前余额”的思维。
- 一开始对题目存在额外套路的预期较高，实际上很多这类题在抓住关键约束后可以直接模拟解决。
