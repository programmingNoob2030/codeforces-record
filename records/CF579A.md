# CF 579A

## 基本信息

- 日期: 2026-09-02
- 分类: bitmasks
- 难度: 1000


## 题目简述

盒子中最开始放入若干细菌。
每经过一天，盒子中的每个细菌都会分裂成两个细菌。
给定目标细菌数量 `n`，求最少需要放入多少个初始细菌，才能经过若干天后得到恰好 `n`个细菌。


## 我的第一印象

一开始认为题目比较简单。
因为任意数字都可以表示为：
- `2 × n`
- `2 × n + 1`
所以认为答案只需要根据奇偶性判断：
- 偶数 → `1`
- 奇数 → `2`
后来发现忽视了题目的实际分裂过程。
一个细菌只能经过若干次分裂得到 `2` 的某次方，而不能直接得到任意数字。
因此像 `5、6、7` 这样的数字，即使可以通过普通数学关系表示，也不能由一个细菌直接得到。


## 最终解法

将 `1e9` 以内的所有 `2` 的幂存入数组，并使用 `map` 记录这些数。
从不超过 `n` 的最大 `2` 的幂开始，从大到小进行贪心：
- 如果当前 `2` 的幂不超过剩余的 `n`，则将其从 `n` 中减去，并将答案加一。
- 如果减去后剩余的 `n` 本身就是 `2` 的幂，则再增加一次计数并结束。
最开始使用 `bool` 数组记录 `2` 的幂，但考虑到 `1e9` 的范围后改用了 `map + vector`。
实现过程中需要保证：
`n - arr[i] >= 0`
否则会出现减去过大的 `2` 的幂导致结果错误。


## 复杂度

Time: O(log n)
 Space: O(log n)


## 不足

- 对题目的过程约束理解不够准确，容易将普通数学关系直接套用到实际过程。
- 对 `2` 的幂与二进制表示之间的关系还不够熟悉，因此采用了 `map + vector` 的实现方式。
- 贪心过程中对剩余值与边界条件的处理还需要更加细致。
