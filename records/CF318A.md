# CF 318A

## 基本信息

- 日期: 2026-08-17
- 分类: math
- 难度: 900


## 题目简述

给两个整数`n`和`k`
构造一个长度为`n`的序列
- 前部分放所有奇数
```text
1,3,5,7,...
```
- 后半部分放所有偶数
```text
2,4,6,8,...
```
要求输出这个序列中第`k`个数字
由于`n`可以达到`1e12`, 不能直接构造整个序列


## 我的第一印象

题目表面上像一个简单模拟题，但是 `n` 和 `k`的范围非常大，无法真的创建长度为 `n` 的数组。
因此需要寻找序列规律。
观察发现：
序列固定分为两个部分：
第一部分：所有奇数
第二部分：所有偶数
所以核心问题变成：
判断第 k 个位置属于奇数区间还是偶数区间。
根据所在区间直接计算对应数字。


## 最终解法

由于 `n` 最大为 `1e12`，不能直接模拟序列。
序列由两部分组成：
1.所有奇数
2.所有偶数
先计算偶数部分开始的位置。
如果 k 在奇数区间：

```java
ans = 1 + (k-1)*2
```
否则：
```java
ans = 2 + (k-even_start)*2
```
直接 O(1) 计算答案。


## 复杂度

Time: O(1) Space: O(1)


## 不足

- 一开始容易误认为需要模拟整个序列，没有第一时间意识到 `1e12`的数据范围意味着必须寻找数学规律。
- 对奇数数量和偶数起始位置的推导过程还不够熟练，需要进一步加强根据边界条件分析序列。
- 实现过程中需要更加注意 `n`为奇数和偶数时的分界差异，避免出现边界错误。
