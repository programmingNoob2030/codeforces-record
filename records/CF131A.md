# CF 131A

## 基本信息

- 日期: 2026-08-28
- 分类: implementation / strings
- 难度: 1000


## 题目简述

给定一个字符串，判断是否因为误触 Caps Lock 导致大小写错误。
如果满足以下条件，则需要修改：
- 第一个字母为小写，其余全部为大写
- 第一个字母和后续所有字母都为大写
否则保持原字符串不变。
修改规则：
- 所有字母大小写翻转。


## 我的第一印象

阅读题目时，第一反应是模拟 Caps Lock 的输入结果。
一开始误解了题目中的 "change the case"，认为是将字符串转换成首字母大写、其余小写的格式。
但是通过重新分析题目描述和示例发现，题目中的 change the case 指的是每个字符进行大小写转换，而不是统一格式化。
因此问题转化为：
1. 判断当前字符串是否符合 Caps Lock 误触条件。
2. 如果符合，将整个字符串进行大小写翻转。
3. 如果不符合，保持原字符串。


## 最终解法

遍历字符串：
记录第一个字符是否为大写。
检查除第一个字符之外的位置：
- 如果存在小写字母，说明不是 Caps Lock 错误，直接输出原字符串。
- 如果不存在小写字母，说明符合错误模式，翻转整个字符串。


## 复杂度

Time: O(n) 
Space: O(1)
