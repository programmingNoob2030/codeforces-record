# CF 405A

## 基本信息

- 日期: 2026-08-18
- 分类: greedy / implementation / sortings
- 难度: 900


## 题目简述

给定`n`个柱子的高度。
初始状态下重力方向向下，柱子稳定排列。
将整个图形旋转 90° 后，重力方向改变，柱子会因为重力重新下落。
要求输出旋转后稳定状态下的柱子高度排列。


## 我的第一印象

刚开始由于题目中的示例图片无法加载，对题意理解不清楚。
直接看文字描述比较抽象，因此尝试从最终答案反推过程。
发现旋转后，原来的柱子高度会受到新的重力影响重新排列。
由于较高的柱子会向重力方向移动，最终所有柱子的高度会按照大小排列。
因此问题本质上等价于：
```text
将所有柱子高度进行排序。
```


## 最终解法

旋转后的重力效果等价于将柱子的高度重新排序。
因此直接对数组进行升序排序即可。
步骤：
1.读取所有柱子高度。
2.使用`sort()`对数组升序排列。
3.输出排序后的结果。


## 复杂度

Time: O(logn) Space: O(n)
