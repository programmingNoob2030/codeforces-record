# CF 122A

## 基本信息

- 日期: 2026-08-25
- 分类: brute force / number theory
- 难度: 1000


## 题目简述

给定一个整数 n。
如果 n 可以被某个幸运数整除，则输出 `YES`。
幸运数定义为：
一个只由数字 `4` 和 `7` 组成的正整数。


## 我的第一印象

第一反应是使用类似线性筛的方式进行预处理。
因为 n 的范围较小：
`n <= 1000`
所以可以提前找出所有满足条件的幸运数，并标记它们的倍数。
开始实现时遇到了边界问题：
- `while(basis <= 1000)` 会导致访问范围错误。
- `while(basis + basis <= 1000)` 会遗漏部分正确答案。
最后发现应该根据当前已经标记的位置判断：
`当前倍数 + 幸运数 <= 1000`


## 最终解法

分两步：
1. 枚举 1 ~ 1000 中所有数字，判断是否只包含数字 4 和 7。
2. 对于每一个幸运数，将它的所有倍数标记为可整除。
最后输入 n：
- 如果 vis[n] == true，说明 n 可以被某个幸运数整除。
- 否则输出 NO。


## 复杂度

Time: O(nlogn)

 Space: O(n)


## 不足

- 对循环边界的理解还不够准确，需要更加明确当前变量表示的含义。
- 一开始关注实现方式（类似筛），但是没有先分析数据范围和可能的简单枚举方案。
- 对预处理问题，需要更加关注“状态定义”和“标记范围”。
