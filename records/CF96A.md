# CF 96A

## 基本信息

- 日期: 2026-08-15
- 分类: Implementation / String
- 难度: 900


## 题目简述

给定一个 0/1 字符串， 判断是否存在连续7个或以上相同字符


## 我的第一印象

看到连续相同字符，想到扫描字符串并统计连续长度。
考虑过区间，但是数据量不大，直接遍历即可。


## 最终解法

遍历字符串，维护当前连续字符数量：
- 如果当前字符和前一个字符相同，count + 1
- 如果不同，count 重置为 1
当 count >= 7 时，说明存在满足条件的连续区间。


## 复杂度

Time: O(n)

 Space: O(1)


## 不足

第一次提交 WA。
原因：
统计连续长度时少计算了第一个字符。
初始化：
len = 0
实际上：
当前连续区间长度应该包含起始字符。
以后处理连续区间问题，需要明确：
统计的是完整长度，还是额外增加长度。
